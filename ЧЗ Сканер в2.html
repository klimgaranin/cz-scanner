1Как запустить
Найди файл cz-scanner-v5.html и двойной клик — откроется в браузере.
Ничего устанавливать не нужно. Интернет не нужен.
2Загрузка файла из Честного Знака
Файл — это .txt или .csv из личного кабинета ЧЗ. В нём каждый DataMatrix-код на новой строке.
Два способа загрузить:
• Перетащи файл мышкой на зону «Загрузить файл ЧЗ»
• Или кликни на неё и выбери файл в проводнике
✓ Если всё ок — появится зелёная полоска с именем файла и количеством кодов.
3Сканирование
Сканируй только DataMatrix.
ШК (штрихкоды EAN-13) программа автоматически игнорирует — можно сканировать всё подряд без разбора, ШК просто пройдут мимо.
Каждый DataMatrix проверяется мгновенно:
ЗначокЧто случилось
✅ ЗелёныйКод из файла, принят
⚠️ ЖёлтыйДубль — уже сканировали, пропускаем
❌ КрасныйКод не из файла ЧЗ — аларм!
⛔ СерыйНераспознанный формат
Список товаров в левой панели обновляется в реальном времени — видно какой ШК сколько уже набрал.
4Какие ошибки программа поймает
СитуацияРеакция
DataMatrix не из этой партии❌ Аларм «Чужой код!»
Один DataMatrix отсканирован дважды⚠️ «Дубликат» — тихо пропускаем
ШК вместо DataMatrixТихо игнорируется
Непонятный код⛔ «Неизвестный формат»
В конце не всё отсканированоВидно в отчёте + список пропущенных
5Даты производства
Переключатель «Запрашивать дату производства» в верхней части левой панели:
Включён — при первом скане нового артикула открывается окно с выбором даты.

Выключен — окно не появляется, сканирование не прерывается. Даты можно добавить вручную через карточки артикулов.
Несколько дат у одного ШК:
В карточке каждого артикула — список дат. Одна помечена «активная» — она записывается в новые сканы. Кнопка «+ добавить дату» добавляет новую и сразу делает её активной. Клик на любую дату — переключить активную. ✕ — удалить.
⚠️ Переключение даты не меняет уже записанные строки в журнале — только новые.
6Отчёт
Кнопка «Завершить и создать отчёт» — внизу левой панели.
✅ Зелёный
Все коды сошлись
❌ Красный
Есть проблемы + что делать
⚠️ Данные живут только в памяти вкладки. Скачай TXT до закрытия браузера!
7Скорость
Программа не тормозит. Приём, проверка, обновление экрана — меньше 20 мс. Одинаково быстро на 100 и на 100 000 кодов.
💡 Совет: включи суффикс CR в настройках сканера (сервисный штрихкод из мануала). Тогда каждый код летит мгновенно без задержки автоопределения. +10–15% к скорости.
?FAQ
Файл не загружается / коды не распознались
Убедись, что в файле каждый код на новой строке и что коды DataMatrix (длинные строки, начинаются с 01 + 14 цифр).
Сканер не вводит текст в поле
Кликни мышкой на поле ввода — появится синяя рамка. После этого сканер будет вводить в него.
Окно с датой мешает при быстром сканировании
Выключи переключатель «Запрашивать дату» вверху левой панели. Даты добавишь вручную позже.
Закрыл браузер — данные пропали
Да, данные хранятся только в памяти вкладки. Всегда скачивай TXT-отчёт до закрытия.
