Запуск Файл ЧЗ Android Сканирование Ошибки Даты Сессии Отчёт FAQ
1Как запустить
Двойной клик на cz-scanner-v6.13.html — откроется в браузере (Chrome / Edge). Интернет и установка не нужны.

На Android (PWA): открой файл в Chrome → меню ⋮ → «Добавить на главный экран». Программа откроется без адресной строки в полноэкранном режиме.
2Загрузка файла ЧЗ
Файл .txt или .csv из личного кабинета Честного Знака. Каждый DataMatrix-код на новой строке.
• Перетащи файл на зону «Загрузить файл ЧЗ»
• или кликни на неё и выбери в проводнике
✓ После загрузки сразу отображаются все товары (артикулы) из файла — затемнённые до первого скана.
Можно загружать несколько разных файлов по очереди — каждый хранится как отдельная сессия. Переключение через баннер «Сохранённые сессии».
3Как открыть на Android
Самый простой способ:
1. Скинь файл на телефон (Telegram, почта, USB)
2. Открой в Диспетчере файлов → папка Загрузки
3. Тапни → «Открыть в Chrome»
4. Меню ⋮ → «Добавить на главный экран» — PWA-режим без адресной строки
Или напрямую из Chrome:
file:///sdcard/Download/cz-scanner-v6.13.html
⚠️ Если файл открывается как текст — зажми → «Поделиться» → Chrome.
Сканер Bluetooth / USB-OTG: режим HID (эмуляция клавиатуры). Подключи, тапни на поле ввода — сканируй.
Суффикс CR: включи в настройках сканера. Каждый код будет отправляться мгновенно.
4Сканирование
Сканер (HID-клавиатура): направь на DataMatrix → курсор должен быть в поле ввода. Код принимается автоматически по суффиксу CR или по концу DataMatrix (символ «=»).
Звуковые сигналы:
🟢 Короткий пик — код принят, всё ок
🟡 Два нисходящих тона — дубликат, пропускается
🔴 Тройной тревожный сигнал — чужой код, не из этой партии
ШК (EAN-13) — игнорируются молча, в журнал не попадают.
Камера: кнопка 📷 → навести на DataMatrix. Работает на телефоне и ноутбуке со встроенной камерой.
5Ошибки и статусы
✅ Принят — DataMatrix из файла ЧЗ, код засчитан
⚠️ Дубликат — этот код уже сканировался в этой сессии, пропускается
❌ ЧУЖОЙ КОД — DataMatrix не из загруженного файла ЧЗ (другая партия, другой поставщик)
⊘ ШК игнорируется — EAN-13 штрихкод, не DataMatrix
При чужом коде звучит тройной тревожный сигнал — не прерывай сканирование, продолжай дальше.
6Даты производства
Если включён тумблер «Указывать дату пр-ва» — при первом скане каждого артикула появится окно выбора даты.
• Формат: ДД.ММ.ГГГГ
• Можно добавить несколько дат на один артикул (разные партии)
• Активная дата — та, которая выбрана кружком
• Дату можно удалить крестиком (✕) если добавлена по ошибке
Даты сохраняются в отчёт и в сессию (восстанавливаются после перезагрузки).
7Сессии и автосохранение
✓ Каждый принятый код автоматически сохраняется в браузере (localStorage). Сессия живёт 7 дней.
Несколько файлов / партий: загружай разные файлы ЧЗ — каждый хранится отдельно по имени файла.
Восстановление после перезагрузки:
1. Загрузи тот же файл ЧЗ
2. Появится баннер «Сохранённые сессии»
3. Нажми «Восстановить» — все принятые коды и даты вернутся
⚠️ «Начать заново» — полностью очищает текущую сессию из памяти.
8Отчёт и экспорт
После завершения нажми «Завершить проверку» — откроется итоговый отчёт.

9FAQ
Коды слипаются в одну строку?
Убедись что в настройках сканера включён суффикс CR. Программа разделяет коды по символу «=» в конце DataMatrix — это работает без суффикса, но CR надёжнее.
GS/FNC1 не определяется?
Программа ловит ASCII 29 через keypress. Работает в Chrome и Edge. Firefox может не поддерживать.
Сессия не восстанавливается?
Имя файла должно совпадать точно. Используй один и тот же файл ЧЗ.
Можно работать без интернета?
Да, полностью. Файл работает локально, данные хранятся в браузере.
Поддерживается ли iOS?
Частично. Safari на iPhone открывает файл, но PWA-режим ограничен. Рекомендуется Chrome на Android.
